# Curation policy

Children only see games whose records have appropriate publisher no-ad evidence and a reviewed status. Some entries have publisher statements but **have not been hands-on play-tested**. Other candidate entries stay hidden pending review. Pricing, download requirements and supported devices must be checked separately; mobile-only apps are not labelled as browser games.

The in-browser Parent/Teacher editor is a local draft tool, not an authenticated publishing back office. New or edited records require review before appearing to children. Export JSON and commit it separately to publish changes.
